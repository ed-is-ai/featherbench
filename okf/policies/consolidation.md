# Results consolidation policy

The aggregate is regenerated by [`results/consolidate.py`](../../results/consolidate.py).

1. One source file is retained per logical run; a resume or re-judged output
   supersedes its raw predecessor.
2. Provider/API errors and retired tasks are excluded.
3. Every surviving answer is re-scored by the current task checker and refusal
   policy.
4. Known residual checker defects are represented as explicit, narrowly scoped
   overrides with a tracking reason.

The output preserves both the final `passed` value and the source-run
`passed_recorded` value. See [benchmark trial records](../tables/benchmark-trial-records.md).
